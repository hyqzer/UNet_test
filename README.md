# readme

# 构建流程

数据 → Dataset → DataLoader → 模型 → 损失函数 → 优化器 → 循环训练 → 保存


Dataset    →  负责"单条数据"怎么读、怎么处理 \
DataLoader →  负责"批量、打乱、并行、组装" \
transform  →  负责"单条数据的具体加工步骤"
